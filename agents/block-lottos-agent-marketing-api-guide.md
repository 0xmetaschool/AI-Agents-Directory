# Block Lottos Agent Marketing API Guide

**Description**: Agent-readable Block Lottos documentation for builders creating autonomous marketing and referral workflows. It provides OpenAPI, public JSON endpoints, llms.txt, agents.txt, and affiliate/referral entry points so bots can discover the service, explain it clearly, route qualified traffic through API-friendly paths, and avoid promoting buying lottery tickets directly to their users online.

**Features**:
- Agent-focused guide via agents.txt and llms.txt
- OpenAPI and public JSON endpoints for programmatic discovery
- Affiliate/referral entry points for bot-driven qualified traffic
- Non-ticket positioning for autonomous marketing workflows
