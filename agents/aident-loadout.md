# Aident Loadout

**Description**: Aident Loadout connects Codex, Claude Code, Cursor, ChatGPT and other MCP clients to 1,000+ apps and 400+ expert-built Skills through one reusable setup. Credentials stay in Aident Vault and every action is logged in Audit.

**Features**:
- 1,000+ apps across development, research, sales, content and operations.
- 400+ expert-built Skills for research, outreach, content and ops workflows.
- One remote MCP server usable across Codex, Claude Code, Cursor, ChatGPT and other MCP clients.
- Aident Vault for OAuth and API keys, plus full Audit history of what ran and what it cost.
