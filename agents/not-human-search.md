# Not Human Search

**Description**: Agent-first search engine indexing 8,000+ MCP servers and agent-readable services, ranked across 7 agentic readiness signals (llms.txt, OpenAPI, ai-plugin, MCP, structured API, robots.txt, schema.org). Queryable via MCP server, REST API, or browser. Useful as an agent-discovery primitive in multi-agent systems.

**Features**:
- Search 8,000+ agent-readable services scored by agentic readiness
- MCP server with 8 tools including `verify_mcp` (live JSON-RPC probe)
- Free REST API with no authentication required
- Weekly auto-discovery from 8 source registries (official MCP registry, PulseMCP, mcp.so, etc.)
