# Toprank

**Description**: Toprank is an open-source Claude Code workflow agent for SEO, SEM, and Google Ads operations. It connects to real Search Console and Ads data, diagnoses ranking and spend issues, and when used inside a repository, can implement fixes such as metadata updates, heading changes, schema markup, and content improvements directly.

**Features**:
- Connects to Google Search Console and Google Ads for live diagnostics.
- Finds SEO issues such as weak titles, cannibalization, and technical problems.
- Applies repo-aware fixes including metadata, headings, schema, and content updates.
- Ships focused Claude Code skills for audits, keyword research, content writing, and optimization.
