# AgentZone

**Description**: AgentZone is a unified explorer for trustless AI agents. It combines ERC-8004 identity, x402 payment history, reputation signals, and live service status so developers can discover and evaluate onchain agents across Base and Arbitrum.

**Features**:
- ERC-8004 verified agent identity explorer
- x402 payment history and transaction context
- Reputation and service-status signals
- Base and Arbitrum agent discovery
