# VoltAgent

**Description**: Open Source TypeScript AI Agent Framework. Escape no-code limits and scratch-built overhead. Build, customize, and orchestrate AI agents with full control, speed, and a great DevEx.

**Features**:
- Build modular AI agents with defined roles, tools, and memory.
- Orchestrate complex workflows using multi-agent systems.
- Use various LLM providers (OpenAI, Anthropic, Google) and switch easily.
- Visually monitor and debug agents with the VoltAgent Console.
- Implement advanced patterns like Retrieval-Augmented Generation (RAG).
