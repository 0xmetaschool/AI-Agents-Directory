# QVeris

**Description**: QVeris connects AI assistants, applications, and workflows to professional data services and tools across finance, company information, social media, life sciences, research, and commerce. Users can discover relevant capabilities, inspect parameters and provider information, and execute supported calls through a hosted MCP connection, SDK, or CLI while reviewing execution status and usage.

**Features**:
- Discover data services and tools relevant to an agent's task.
- Inspect supported parameters, schemas, and provider information.
- Connect through hosted MCP, SDK, or CLI integration methods.
- Review execution status and usage for supported capability calls.
