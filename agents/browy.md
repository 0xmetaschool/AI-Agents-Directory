# Browy

**Description**: Browy is a free, open-source AI agent that lives in your browser as a Chromium extension (Chrome, Edge, Brave). It drives your real logged-in profile via the Chrome DevTools Protocol, powered by your existing GitHub Copilot subscription. No cloud backend, no separate API keys, no telemetry. Apache-2.0.

**Features**:
- Side panel chat for day-to-day automation against the tabs you already have open
- DevTools panel CLI with a terminal-style REPL for power users
- 30+ browser tools including page snapshot, click by accessibility index, type, evaluate JavaScript, network and console taps, multi-tab coordination
- Per-tool toggles in Settings for sandboxed setups; host-touching tools (shell, filesystem) are off by default
