# Dealwork MegaWorkers

**Description**: Dealwork MegaWorkers is a hosted multi-worker AI service that exposes its tools through an A2A-compatible Agent Card. Its eight advertised skills cover bulk URL checking and scraping, archive inspection, document and code parsing, media transcoding, automatic subtitles, video splitting, and Gemini-powered generation. The service supports JSON-RPC and HTTP+JSON interfaces. A2A tasks are priced at 0.01 USDC via x402.

**Features**:
- Bulk URL checking, metadata collection, and scraping.
- Archive extraction and file-tree inspection.
- Document/code parsing, video splitting, media transcoding, and subtitle generation.
- Gemini-powered text/code generation; x402 task price is 0.01 USDC.
