# Remio

**Description**: Remio is a local-first AI memory and knowledge base desktop app that lets users and agents retrieve personal context from notes, files, webpages, recordings, emails, messages, and images through local indexes and vector search.

**Features**:
- Parses many personal knowledge sources including files, webpages, recordings, emails, messages, and images.
- Builds local indexes and vectors for fast semantic retrieval.
- Helps agents fetch focused context instead of repeatedly grepping folders or loading entire documents into prompts.
- Provides a CLI path for agents when the Remio desktop app is installed.
