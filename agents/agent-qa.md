# agent-qa

**Description**: agent-qa turns natural-language test plans into repeatable Web, Android, and iOS checks. Its persistent memory engine reuses validated testing knowledge across runs, while self-improvement retains lessons only after validation. Developers can author tests, inspect failures, and query knowledge through the CLI, dashboard, MCP server, or agent skills, helping automate product regression testing.

**Features**:
- Natural-language testing across Web, Android, and iOS.
- Persistent memory with validated self-improvement across runs.
- Four agent skills for authoring, failure triage, debugging, and knowledge queries.
- CLI, dashboard, and MCP access to tests and run evidence.
