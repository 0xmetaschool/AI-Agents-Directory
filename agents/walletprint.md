# WalletPrint

**Description**: Behavioral risk scoring SDK for agent wallets. Flags anomalies before transactions are signed using wallet behavioral history. Open source with a free tier. Integrates with ZeroDev, LangChain, and Coinbase AgentKit. Drop-in npm package for any agent signing flow.

**Features**:
- Behavioral anomaly detection before transaction signing
- Integrates with ZeroDev, LangChain, and Coinbase AgentKit
- Open source SDK with free tier
- Wallet behavioral history analysis
