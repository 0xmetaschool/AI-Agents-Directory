# CoderPlan

**Description**: CoderPlan is a unified LLM API gateway for developers, providing OpenAI-compatible access to Claude, GPT, Gemini, DeepSeek, and Grok models. Pay-as-you-go at approximately 7% of official pricing with Alipay and WeChat Pay support. Hong Kong and Singapore nodes ensure low latency for Chinese developers.

**Features**:
- OpenAI-compatible API endpoint — one-line config for Cursor, Claude Code, Cline, and more.
- Multi-model support — Claude, GPT, Gemini, DeepSeek, Grok through a single gateway.
- Pay-as-you-go pricing at ~7% of official API costs with 10 RMB minimum top-up.
- Direct access from mainland China — no VPN required, Alipay/WeChat Pay supported.
