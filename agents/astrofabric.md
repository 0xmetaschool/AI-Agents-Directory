# AstroFabric

**Description**: AstroFabric is an agentic AI platform where specialist agents run growth, revenue and digital operations work: SEO, advertising, outbound pipeline, competitive intelligence, creative, lifecycle and reporting. Missions execute through metered tools with enforced budgets, approval-gated writes and a full transcript of every step, callable from the console, REST API or hosted MCP server.

**Features**:
- Specialist agents that plan and execute complete missions with receipts
- Metered tools spanning SEO, ads, outbound, competitive intel and CRM ops
- Hosted MCP server and REST API with OAuth 2.1 or API-key auth
- Enforced budgets and approval-gated writes on every autonomous action
