# Komos

**Description**: Komos is an AI automation platform for regulated operations teams that need reliable browser work across portals, documents, integrations, and exception queues. It turns demonstrated workflows into reusable tasks with schedules, API triggers, credential handling, evidence capture, logs, and human review for CRAs, insurance teams, finance teams, and other operations groups.

**Features**:
- Browser automation for portals without stable APIs.
- API triggers, schedules, retries, logs, and human review.
- Evidence capture for screenshots, downloads, and structured output.
- Regulated ops playbooks for CRA, insurance, and banking workflows.
