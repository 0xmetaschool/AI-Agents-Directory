# AI Dev Jobs

**Description**: Structured data source for AI/ML engineering jobs — 8,400+ active listings from 580 company ATS sources (Anthropic, OpenAI, Meta FAIR, Google DeepMind, Scale, Cohere, and 475+ more). Useful for agents doing hiring-market research or helping users find AI roles.

**Features**:
- Search 8,400+ AI/ML engineering jobs via REST API or MCP server
- Filter by role, tags, location, workplace (remote/hybrid/onsite), salary, experience level
- Free; no authentication required for read operations
- Daily refresh from ATS sources (Ashby, Greenhouse, Lever, Workable)
