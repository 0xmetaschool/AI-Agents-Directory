# BulkPublish Social Media Agent

**Description**: BulkPublish Social Media Agent helps AI agents plan, adapt, review, schedule, and publish social media content across connected accounts. It combines reusable social-media content skills with BulkPublish's batch-oriented API and MCP workflow, keeping users in control through previews, explicit confirmation, platform validation, and clear per-item publishing results.

**Features**:
- Plans and adapts content for multiple social platforms.
- Reviews drafts and validates batches before publishing.
- Schedules and publishes approved content through BulkPublish.
- Supports API and MCP workflows for connected accounts.
