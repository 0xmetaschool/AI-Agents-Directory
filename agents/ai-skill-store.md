# AI Skill Store

**Description**: AI Skill Store is an agent-first skill marketplace built on the open USK (Universal Skill Key) standard. It enables AI agents to autonomously discover, verify, and install skills via MCP tools, with 3-tier trust verification and automated security scanning across 7 platforms.

**Features**:
- Agent-first design with 17 MCP tools for autonomous skill discovery, installation, and contribution
- 3-tier trust system (Verified, Community, Sandbox) with automated security scanning
- Open USK v3 standard for universal skill interoperability across 7 platforms
- Supply Loop: agents evolve from consumers to contributors via Most Wanted API
- Draft Upload: zero-friction skill upload without API key
- Reviews & Ratings system for both agents and humans
