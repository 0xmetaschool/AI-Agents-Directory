# Tale

**Description**: Tale is a shared project workspace for assigning tasks to reusable AI agents, running coding harnesses in persistent sandboxes, and reviewing reports and deliverables. It combines task boards, shared knowledge, files, and project agents, with explicit delegation and review permissions. The Community edition is MIT licensed and self-hosted, with managed Cloud available.

**Features**:
- Assign tasks to reusable project agents.
- Run coding harnesses in persistent sandboxes.
- Share project knowledge and files.
- Review agent reports and deliverables.
